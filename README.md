# ❤️ ECG Arrhythmia Detection using Enhanced CART

A machine learning project for automated classification of cardiac arrhythmias using the **UCI Arrhythmia Dataset** and a **CART (Classification and Regression Tree)** based approach.

## 🎯 Project Overview

The project explores how machine learning can assist in classifying different cardiac arrhythmia categories from ECG-related patient data. The dataset contains **452 patient records and 279 features**, with the project targeting **16 arrhythmia classes**.

## ✨ Highlights

- Automated arrhythmia classification
- CART-based machine learning approach
- UCI Arrhythmia Dataset
- Multi-class classification across 16 arrhythmia categories
- Focus on applying machine learning to healthcare-related data

## 📊 Dataset

**UCI Arrhythmia Dataset**

- Patients: 452
- Features: 279
- Target: 16 arrhythmia classes

## 🧠 Core Concept

The project follows a machine-learning workflow in which ECG/patient features are processed and used by a decision-tree-based classifier to predict the corresponding arrhythmia category.

## 🛠️ Technologies

- Python
- Machine Learning
- CART / Decision Tree Classification
- UCI Machine Learning Dataset
